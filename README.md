# ECO: Save the World

ECO: Save the World es un juego realizado para concientizar al jugador acerca del reciclaje y la contaminación en el medio ambiente.

Este juego fue realizado como parte de mi proyecto en una competición de desarrollo de software a nivel Latinoamérica y hoy forma parte de mi portafolio.

## Tecnologías

- Motor: Unity
- Plataforma: Windows (build ejecutable)

## Código fuente

La carpeta [`scripts/`](scripts) contiene los scripts en C# del juego (jugador, cámara, basura, botes de reciclaje, enemigos, proyectiles, contadores y más), junto con sus archivos `.meta` de Unity.

## Cómo jugar

1. Clona o descarga este repositorio.
2. Ejecuta `ECO save the world.exe`.

> Nota: mantén juntos el `.exe`, `UnityPlayer.dll` y las carpetas `ECO save the world_Data` y `MonoBleedingEdge`, ya que el juego los necesita para funcionar.
